# Tethered CubeSat simulation — project brief

## Context

Feasibility study for a CUBICS 2026 Stream 1 proposal (Canadian Space Agency). A 6U CubeSat in the 2x3U format separates in orbit into two 3U spacecraft joined by several cables driven by winches. The cable mechanism is the primary payload. The purpose of this repository is to produce verifiable numbers and figures for the application, not to build flight software.

Language: Python 3.11+, NumPy, SciPy, Matplotlib. No MATLAB. Every figure in the report must be generated by a script in this repository.

## Physical model

In-plane dumbbell in a circular orbit, with `l` the half-separation and `phi` the libration angle measured from the local vertical:

```
l''   = l * ((phi' + n)^2 - n^2 * (1 - 3 cos(phi)^2)) - T / m_eq
phi'' = -2 * (l'/l) * (phi' + n) - 3 * n^2 * sin(phi) * cos(phi)
```

with `m_eq = m1*m2/(m1+m2) = 2.0 kg`.

Equilibrium check, which the code must satisfy before anything else is trusted: setting `phi = 0`, `phi' = 0`, `l' = 0`, `l'' = 0` gives `T = 3 n^2 l m_eq`.

## Cable model

The cable is unilateral. It pulls, never pushes.

```
T = max(0.0, T0 + c * l_dot + k * (l - l_cmd))
```

Log every crossing of the inner expression through zero. Slack events are the dominant failure mode of this mission class and the count is a reportable result.

Cable mass is 0.05 % of the end masses, so tension is uniform along the cable and a lumped two-body model captures the dominant dynamics. Flexible cable modelling is deferred until the end-of-deployment rebound is shown to be sizing.

## Known pitfalls — do not repeat these

- Deployment under gravity gradient is exponential, `x = x0 cosh(sqrt(3) n t)`, not uniformly accelerated. A constant-acceleration estimate gives 18 minutes instead of the correct 61 minutes.
- When sizing the wheels, subtract the orbital rate. The system already rotates at `n` once per orbit, sustained by the gravity gradient torque at no cost.
- Only radial alignment produces tension. The out-of-plane term `-n^2 z` pushes the bodies back towards the orbital plane and leaves the cable slack.
- The sum of cable tensions is bounded by the gravity gradient force. Two bodies joined only by cables admit no self-stress state, so there is no preload beyond what the gradient supplies.
- Fibre axial thermal expansion is negative, roughly -1e-5 /K for high-modulus polyethylene and a few times 1e-6 /K for aramid.
- The cable operates at 2.3e4 Pa, about 1e-5 of breaking strength, so the elastic elongation computed from the Young modulus is a lower bound.

## Repository layout

```
src/        model, control laws, cable mechanics, constants
cases/      one script per study case, each writing to figures/
tests/      regression tests against the reference values above
figures/    generated, never edited by hand
report/     LaTeX source, figures pulled from figures/
```

## Conventions

- SI units everywhere, no exceptions, no implicit conversions.
- Constants live in one module and are imported, never retyped in a case script.
- Every case script prints the numbers it produces so they can be pasted into the report and traced back.
- Figures: black only, no colour, no grid background, serif font, vector PDF output sized for a single journal column.
- Docstrings state the equation implemented and its source.

## Study cases to produce

1. Deployment from 0.1 m to 100 m under gravity gradient alone, with the braking law `T = T0 + c * l_dot`, reporting tension, length, libration and slack count.
2. The same with an initial stacer impulse of 0.2 m/s, to show that the terminal separation rate is set by the gradient and not by the impulse.
3. Thermal transient at the terminator: a commanded length perturbation of 0.12 m with a 30 s time constant, compared with and without active compensation.
4. Staged deployment to 5, 20, 50 and 100 m with hold periods, reporting the energy to dissipate at each stage.
5. Tension distribution among three cables under a relative attitude disturbance, reporting the torque produced and the angle at which the first cable goes slack.
